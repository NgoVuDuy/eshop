## Giới thiệu

- Eshop là một nền tảng thương mại điện tử tập trung vào bán các thiết bị điện tử như điện thoại, laptop, máy giặt, ...
- Một bộ **RESTful APIs** bằng Spring boot 3x.
- Xây dựng các tính năng như quản lý người dùng, danh mục, thương hiệu, giỏ hàng, đánh giá, yêu thích, đơn hàng.

## Công nghệ

- **Framework**: Spring boot 3.4.7
- **Database**: MySQL
- **Database Migration**: Liquibase
- **Authentication & Authorization**: JWT
- **Khác**: Bucket4j, Cloudinary
